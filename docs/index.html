Quick Start

Open Terminal (Cmd + Space → type Terminal → Enter), paste this, and hit Enter:

bash <(curl -fsSL https://raw.githubusercontent.com/otto-ai-labs/setupai.dev/main/setup.sh) --light

The script asks for your Git name & email, then shows checkbox menus. Everything useful is already checked. Press D to confirm each menu. Takes ~20 min.

How it works

  1. Pre-flight — enter your Git name and email. Used to configure Git and generate your SSH key.
  2. Interactive menus — checkbox menu for each category. --light pre-deselects the heavy tools. Toggle anything back on, press D to confirm.
  3. Automated install — Homebrew, Python, Node, and your selected tools. Walk away for ~20 minutes.
  4. Shell setup — Oh My Zsh, Starship prompt, aliases, and PATH all written to ~/.zshrc.
  5. Done — open a new terminal, add your SSH key to GitHub, set API keys, start shipping.

After the script finishes

  1. Open a new terminal window (or run source ~/.zshrc).
  2. Add your SSH key to GitHub — run cat ~/.ssh/id_ed25519.pub, paste it at github.com/settings/keys.
  3. Set your API keys in ~/.extra (gitignored, auto-loaded by your shell): 
    # ~/.extra
export ANTHROPIC_API_KEY='sk-ant-...'
export OPENAI_API_KEY='sk-...'
  4. Run claude or open cursor . in your project folder and start building.
  5. Restart your Mac to apply all system-level changes.
