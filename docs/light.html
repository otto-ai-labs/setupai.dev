The lean version. No bloat. Just Claude, Cursor, and the tools you actually reach for on a build day.

Install

Open Terminal (Cmd+Space → Terminal → Enter) and run:

bash <(curl -fsSL https://raw.githubusercontent.com/otto-ai-labs/setupai.dev/main/setup.sh) --light

The script asks for your Git name & email, then shows a checkbox menu for each category. Everything useful is already checked — just press D to confirm and move on. Done in ~20 minutes.

Prefer to review the scripts first?

# Download and inspect before running
git clone https://github.com/otto-ai-labs/setupai.dev.git
cd setupai.dev
./setup.sh --light

After the script finishes

  1. Open a new terminal window — or run source ~/.zshrc.
  2. Add your SSH key to GitHub: 
    cat ~/.ssh/id_ed25519.pub
    Paste the output at github.com/settings/keys.
  3. Set your API keys in ~/.extra (gitignored, auto-loaded by your shell): 
    # ~/.extra
export ANTHROPIC_API_KEY='sk-ant-...'
export OPENAI_API_KEY='sk-...'
  4. Start building: 
    claude        # Claude Code CLI
cursor .      # open project in Cursor
  5. Restart your Mac to apply all system-level changes.

Want the full stack?

Drop the --light flag to get the complete interactive install — Ollama, Jupyter, PostgreSQL, VS Code, Raycast, and everything else.

bash <(curl -fsSL https://raw.githubusercontent.com/otto-ai-labs/setupai.dev/main/setup.sh)

Other flags: --yes auto-upgrades without prompting  ·  --minimal installs languages + shell only  ·  --skip-web skips JS toolchain.
